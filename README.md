# Entrepreneur Simulator Game

A realistic business simulation game built with Python and Pygame.

## Vision

Entrepreneur Simulator is a single-player management game where you build and run your own company from scratch. Starting with an idea and limited capital, you navigate the real challenges of entrepreneurship: hiring talent, managing cash flow, satisfying clients, scaling operations, and surviving market shifts.

The goal is to offer a faithful and educational simulation of what it actually means to build a business — with strategic depth, emergent storytelling, and meaningful decisions at every stage.

## Tech Stack

- **Language:** Python 3.12+
- **Framework:** Pygame
- **Architecture:** ECS (Entity-Component-System)

## Getting Started

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install pygame
python src/main.py
```
